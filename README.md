# Product Sales Analysis

## About the Project
This project analyzes product sales using Python, Pandas, and Matplotlib.

## Features
- Display product information
- Calculate final prices after discounts
- Calculate total sales
- Identify best-selling products
- Identify worst-selling products
- Calculate monthly average sales
- Create three charts:
  - Bar Chart
  - Pie Chart
  - Line Chart

## Technologies
- Python
- Pandas
- Matplotlib

## Installation
pip install -r requirements.txt

## Run the Project
python main.py
